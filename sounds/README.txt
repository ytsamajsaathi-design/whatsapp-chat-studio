=============================================
  WhatsApp Chat Studio — Custom Sound Files
=============================================

Drop your downloaded sound files here with EXACTLY these filenames:

  sent.mp3       ← Sender / Outgoing message sound
                   (Pixabay: search "Bubble Pop 06")

  received.mp3   ← Receiver / Incoming message sound
                   (Pixabay: search "WhatsApp" notification)

HOW TO DOWNLOAD FROM PIXABAY:
  1. Go to https://pixabay.com/sound-effects/
  2. Search for the sound name above
  3. Click Download → choose MP3
  4. Rename the file to sent.mp3 or received.mp3
  5. Place it in THIS folder (sounds/)
  6. Refresh the app in your browser

NOTE: The app automatically detects these files on startup.
      If a file is missing, it falls back to a built-in
      synthesized sound automatically — no errors.
